# お店カレンダー工房

飲食店の営業カレンダーを作り、PNGやA4印刷用に出力できるブラウザアプリです。

[公開サイト](https://taiganomad.github.io/omise-calendar-maker/)

GitHub Pages は `main` ブランチのルートを配信します。公開サイトの更新は `main` に反映してください。アプリは静的な HTML・CSS・JavaScript で構成され、ビルドや環境変数は不要です。ローカルでは `python3 -m http.server 8765` で確認できます。

## 予定と設定の引き継ぎ

「お店情報」→「バックアップ・引っ越し」で、元のサイトからバックアップを保存し、移行先で読み込みます。入力内容はブラウザに保存されます。バックアップファイルには入力内容が含まれるため、GitHub に追加せず、ご自身の端末で保管してください。
